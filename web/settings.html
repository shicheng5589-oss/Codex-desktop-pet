底部按钮与功能方案

撤回 / 铅笔 / 橡皮擦 支持独立配置：每个按钮的单击、右键都可选择功能。 每次触发都会先弹出「确认 / 取消」，确认后才执行；任何一项都能选「无功能」。

状态对应的表情

模型里一共找到 0 个表情，按喜好改就行，改完立即生效。

表情白名单

不想要的表情（比如那些"道具 / 贴纸"类，像 晕晕、吐魂、各种贴纸） 在这里取消勾选，就再也不会出现了；状态映射和随机心情都会跳过它们。

动作与表情播放

模型里有 0 个动作、0 个表情。 动作若一直循环（比如那段 4 秒的闲置表演），可以把它们单独关掉。
