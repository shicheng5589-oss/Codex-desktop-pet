# 文件速查：哪些要留、哪些能删、哪些根本不会进仓库

面向使用者的说明在根目录 **[README.md](../README.md)**；这份只是给「想整理文件夹」的人看的速查表。

## 一、程序本体（必须留）

| 文件 / 目录 | 说明 |
| --- | --- |
| `run.py` | 宿主程序：透明窗口、鼠标互动、拖动、缩放、进度卡片、设置窗口、日志 |
| `codex_state.py` | 只读 `~/.codex/` 的本地记录，翻译成 9 个状态 |
| `settings_store.py` | 设置读写 + 老配置自动升级 |
| `web/` | 界面：`pet.*`（桌宠本体）、`settings.*`（设置窗口）、`card.*`（独立卡片，默认不用）、`lib/`（渲染库）、`model/`（模型） |
| `vendor/` | Python 依赖（pythonnet + WebView2 .NET 组件，约 24MB）。删了也能跑，但要改用 `pip install -r requirements.txt` |
| `pet-launcher.ps1` | 所有启动脚本最终都调它：找 Python、拉起 `run.py`、管开机自启 |

`web/model/` 里除了程序真正读的 `settings.json` + `c_0120.*` + 贴图 + 动作/表情 json，
还有几个 **VTube Studio 的工程文件**（`c_0120.vtube.json`、`items_pinned_to_model.json`、
`prop_expressions.json`、`c_0120.model3.json`）：程序不读它们，但如果你还在 VTube Studio 里
维护这个模型，建议留着；确定不用再删。

## 二、脚本（日常用）

| 脚本 | 作用 |
| --- | --- |
| `启动桌宠.cmd` / `启动桌宠.vbs` | 启动（cmd 能看到报错；vbs 无黑框） |
| `停止桌宠.cmd` / `重启桌宠.cmd` | 关闭 / 关闭再启动 |
| `诊断.cmd` | 自检一次并打印日志，导出 `selftest.png` |
| `开机自启-开启.cmd` / `-关闭.cmd` | 登录 Windows 自动启动 |
| `跟随Codex启动-开启.cmd` / `-关闭.cmd` | 随 Codex 一起启动（本体是 `codex-watcher.ps1`，每 4 秒看一眼进程） |
| `清理缓存-释放空间.cmd` | 删除 `.webview2/` 缓存（通常 200–400MB） |
| `恢复道具动画.cmd` + `restore_props.py` + `web/model_backup_props/` | 把被屏蔽的道具动画（锤子/猫手/泡泡…）恢复回模型 |
| `黑边处理-新旧版切换.cmd` | 缩放后偶发黑边时的两套重画强度切换 |

## 三、运行期生成（**可以随时删**，下次启动会重建）

| 文件 / 目录 | 说明 |
| --- | --- |
| `pet.log` | 运行日志（超过 512KB 自动截断；设置里可一键清空） |
| `watcher.log` | 「跟随 Codex 启动」的监视器日志 |
| `pet_settings.json` | 你的全部设置（删掉 = 回默认） |
| `pet_position.json` | 桌宠上次的位置 |
| `pet.pid` / `stop.request` | 单实例标记 / 停止请求 |
| `.webview2/`、`.webview2-runtime/` | WebView2 的浏览器缓存（几百 MB，占空间大头） |
| `__pycache__/`、`selftest.png` | Python 缓存 / 自检截图 |

> 上面这些**都已经写进 `.gitignore`**，`git add .` 不会把它们带进仓库
> （日志和设置里有你本机的路径、位置、习惯，别不小心打包发给别人）。

## 四、只在本机存在、不发布的东西

| 文件 | 说明 |
| --- | --- |
| `run.py.bak-<日期>` | 改代码前的快照（回滚用） |
| `还原-缩放黑边修复.cmd` | 用上面那个快照把 `run.py` 换回去（依赖备份文件，所以也不发布） |
| `黑边修复-用旧版.txt` | 由 `黑边处理-新旧版切换.cmd` 生成的开关文件 |

## 五、占用一览（实测，详见 README 的「性能实测」）

| 项目 | 占用 |
| --- | --- |
| 程序本体（代码 + 界面 + 模型 + 文档） | 约 15 MB |
| `vendor/` | 约 24 MB |
| `web/model_backup_props/` | 约 4.3 MB |
| `.webview2/` 缓存 | 200–400 MB（可清） |
| 运行时内存（整棵树） | 约 282 MB（宿主 104 + WebView2 178） |
| 空闲 CPU | 单核约 2.7%（20 核机器上约 0.14%） |
